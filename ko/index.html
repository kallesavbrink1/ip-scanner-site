IP Scanner

네트워크의 모든 기기를 찾아 식별합니다

내 네트워크에 무엇이 있는지 확인해 보세요. 몇 초 만에 Wi-Fi를 스캔하여 모든 기기의 이름, 기기 종류, 주소, 응답 속도를 한눈에 볼 수 있습니다.

앱은 현재 영어로 제공됩니다.

기기

  • 휴대폰, 컴퓨터, TV, 스피커, 프린터, 공유기, 스마트홈 기기를 찾아 식별합니다
  • 기기가 알려 주면 모델, 제조사, 소프트웨어를 표시합니다
  • 기기가 직접 알려 주면 MAC 주소를 표시합니다
  • 새 기기와 오프라인 기기, 스캔 기록, 직접 지정한 이름과 메모
  • iPhone과 iPad에서 작동합니다

네트워크

  • 내 주소, 공유기, 서브넷, DNS 서버를 한눈에 확인
  • 공인 IP 주소와 국가, 연결 확인, 속도 테스트
  • 열려 있는 Telnet이나 FTP 같은 간단한 보안 안내
  • 결과를 CSV, JSON, PDF로 내보내기

도구

  • Ping – 지연 시간과 패킷 손실
  • Traceroute – 경로와 홉별 지연 시간
  • Port Scanner – 호스트에서 열려 있는 TCP 포트
  • DNS Lookup – A, AAAA, MX, TXT 등의 레코드
  • HTTP Inspector – 상태, 헤더, TLS, 소요 시간
  • Subnet Calculator – CIDR, 마스크, 호스트 범위
  • Wake on LAN – 절전 중인 컴퓨터 깨우기

설계부터 개인정보 보호

계정 없음, 광고 없음, 추적 없음. 스캔 결과는 내 기기에만 남습니다. IP Scanner는 내가 소유했거나 테스트가 허용된 네트워크에서만 사용하세요.

자주 묻는 질문

IP Scanner는 모바일 데이터에서 작동하나요?

아니요. 연결된 Wi-Fi 또는 이더넷 네트워크를 스캔합니다. 모바일 데이터에는 스캔할 로컬 네트워크가 없습니다.

앱이 로컬 네트워크 접근 권한을 요청하는 이유는 무엇인가요?

앱이 네트워크의 기기와 통신하려면 iOS에서 사용자의 허용이 필요합니다. 허용하지 않으면 스캔해도 아무것도 찾지 못합니다. 설정 › 개인정보 보호 및 보안 › 로컬 네트워크에서 변경할 수 있습니다.

이름이 없는 기기가 있는 이유는 무엇인가요?

기기가 네트워크에서 이름을 알려 줄 때만 이름이 표시됩니다. 어떤 기기든 직접 이름을 바꿀 수 있습니다. 기기를 열고 Edit를 탭하세요.

모든 기기의 MAC 주소가 보이지 않는 이유는 무엇인가요?

iOS에서는 앱이 MAC 주소를 직접 읽을 수 없습니다. 기기가 직접 알려 줄 때만 표시됩니다. 휴대폰은 네트워크마다 임의의 비공개 주소를 사용하는 경우가 많습니다.

내 데이터가 어딘가로 전송되나요?

스캔 결과, 이름, 메모는 내 기기에만 남습니다. 앱은 몇 가지 인터넷 요청만 보냅니다. 공인 IP 주소와 국가, 연결 확인, 그리고 시작했을 때의 속도 테스트입니다. 개인정보 처리방침을 확인하세요.

Wake on LAN으로 컴퓨터가 깨어나지 않습니다.

컴퓨터에서 Wake on LAN이 켜져 있어야 하며, 보통 이 네트워크에 이더넷으로 연결되어 있어야 합니다. 일부 공유기는 브로드캐스트 패킷을 차단합니다.

기기가 켜져 있는데 오프라인으로 표시됩니다.

일부 기기는 절전 상태이거나 네트워크 확인에 응답하지 않습니다. 기기 목록을 아래로 당겨 다시 스캔하세요.
