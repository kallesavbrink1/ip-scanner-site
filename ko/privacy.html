English (original)

IP Scanner는 연결된 로컬 네트워크의 기기를 나열하고 식별합니다. 계정, 분석, 광고, 추적이 없습니다. 개발자는 앱에서 어떤 데이터도 받지 않습니다.

내 기기에 남는 정보

스캔 결과, 직접 편집한 기기 이름, 메모, 즐겨찾기, 스캔 기록, 도구 기록은 내 기기에만 저장됩니다. 다른 앱의 데이터와 마찬가지로 기기의 일반적인 iCloud 또는 컴퓨터 백업에 포함됩니다. 앱의 Settings › Forget All Devices에서 또는 앱을 삭제하여 모두 지울 수 있습니다.

앱은 사용자가 시스템 공유 시트를 통해 직접 선택할 때만 데이터를 내보내거나 공유합니다.

로컬 네트워크 접근

기기를 찾기 위해 앱은 iOS에 로컬 네트워크 접근 권한을 요청합니다. 그런 다음 각 기기가 무엇인지 파악하기 위해 해당 네트워크의 주소와 통신합니다(ping, 일반적인 포트에 대한 연결 시도, Bonjour·UPnP·NetBIOS 이름 조회, 기기 자체의 웹 페이지). 이 트래픽은 로컬 네트워크 안에서만 오갑니다.

인터넷으로 전송되는 정보

일부 기능은 인터넷의 서비스에 연결해야 합니다. 이 요청은 내 기기에서 직접 전송되며 개발자는 볼 수 없습니다.

  • 공인 IP와 국가(Network 탭): 기기가 Cloudflare(www.cloudflare.com)에 공인 IP 주소와 해당 주소가 속한 국가를 요청합니다. 실패하면 api64.ipify.org에 IP 주소만 요청합니다. 이 서비스들은 모든 인터넷 요청과 마찬가지로 공인 IP 주소를 받습니다. 계정이나 토큰은 사용하지 않습니다.
  • 연결 확인(Network 탭): 앱은 Cloudflare, Google, Quad9의 공개 DNS 서버가 연결 시도에 얼마나 빨리 응답하는지 측정합니다. 개인 데이터는 전송되지 않습니다.
  • 속도 테스트(시작했을 때만): Cloudflare의 속도 테스트 서버(speed.cloudflare.com)와 데이터를 내려받고 올립니다.
  • 실행하는 도구: Ping, Traceroute, Port Scanner, DNS Lookup, HTTP Inspector는 입력한 호스트나 DNS 서버에만 연결하며 그 외에는 연결하지 않습니다.

이 서비스들은 각자의 개인정보 처리방침에 따라 요청을 처리합니다.

어린이

앱은 어린이를 포함하여 누구의 개인 데이터도 수집하지 않습니다.
