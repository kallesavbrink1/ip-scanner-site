IP Scanner

ネットワーク上のすべての機器を見つけて識別します

ネットワークに何があるかを確認できます。Wi-Fiを数秒でスキャンし、すべての機器の名前、種類、アドレス、応答の速さを一覧で表示します。

アプリは現在、英語で提供されています。

機器

  • スマートフォン、パソコン、テレビ、スピーカー、プリンタ、ルーター、スマートホーム機器を見つけて識別します
  • 機器が通知した場合は、モデル、メーカー、ソフトウェアを表示します
  • 機器自身が通知した場合は、MACアドレスを表示します
  • 新しい機器とオフラインの機器、スキャン履歴、独自の名前とメモ
  • iPhoneとiPadで使えます

ネットワーク

  • 自分のアドレス、ルーター、サブネット、DNSサーバを一目で確認
  • パブリックIPアドレスと国、接続チェック、速度テスト
  • 開いているTelnetやFTPなど、簡単なセキュリティのヒント
  • 結果をCSV、JSON、PDFで書き出し

ツール

  • Ping – 遅延とパケット損失
  • Traceroute – 経路とホップごとの遅延
  • Port Scanner – ホストの開いているTCPポート
  • DNS Lookup – A、AAAA、MX、TXTなどのレコード
  • HTTP Inspector – ステータス、ヘッダ、TLS、所要時間
  • Subnet Calculator – CIDR、マスク、ホスト範囲
  • Wake on LAN – スリープ中のコンピュータを起動

プライバシーを重視した設計

アカウント不要、広告なし、トラッキングなし。スキャン結果はお使いの機器の中にとどまります。IP Scannerは、自分が所有している、またはテストを許可されているネットワークでのみ使用してください。

よくある質問

IP Scannerはモバイルデータ通信で使えますか？

いいえ。接続しているWi-FiまたはEthernetのネットワークをスキャンします。モバイルデータ通信にはスキャンできるローカルネットワークがありません。

アプリがローカルネットワークへのアクセスを求めるのはなぜですか？

アプリがネットワーク上の機器と通信するには、iOSであなたの許可が必要です。許可がないと、スキャンしても何も見つかりません。設定 › プライバシーとセキュリティ › ローカルネットワークで変更できます。

名前のない機器があるのはなぜですか？

機器がネットワーク上で名前を通知した場合にのみ名前が付きます。どの機器でも自分で名前を変更できます。機器を開いて「Edit」をタップしてください。

すべての機器のMACアドレスが表示されないのはなぜですか？

iOSでは、アプリがMACアドレスを直接読み取ることはできません。機器自身が通知した場合にのみ表示されます。スマートフォンは、ネットワークごとにプライベートなランダムアドレスを使うことがよくあります。

データはどこかに送信されますか？

スキャン結果、名前、メモはお使いの機器の中にとどまります。アプリが行うインターネットへのリクエストはごくわずかです。パブリックIPアドレスと国、接続チェック、そして開始したときの速度テストです。プライバシーポリシーをご覧ください。

Wake on LANでコンピュータが起動しません。

コンピュータ側でWake on LANが有効になっている必要があり、通常はこのネットワークにEthernetで接続されている必要があります。ブロードキャストパケットをブロックするルーターもあります。

機器がオンなのにオフラインと表示されます。

スリープしている機器や、ネットワークの確認に応答しない機器があります。機器リストを下に引いて、もう一度スキャンしてください。
