English (original)

IP Scanner 会列出并识别你所连接的本地网络中的设备。它没有账户、分析、广告，也不做追踪。开发者不会从该 App 收到任何数据。

保留在你设备上的内容

扫描结果、你编辑的设备名称、备注、收藏、扫描记录和工具记录仅存储在你的设备上。和其他 App 的数据一样，它们会包含在你设备常规的 iCloud 或电脑备份中。你可以在 App 的 Settings › Forget All Devices 中全部删除，或直接删除该 App。

只有当你选择通过系统的共享面板导出或共享时，App 才会导出或共享数据。

本地网络访问

为了发现设备，App 会请求 iOS 允许其访问你的本地网络。随后，它会与该网络上的地址通信（ping、对常用端口的连接尝试、Bonjour、UPnP 和 NetBIOS 名称查询，以及设备自身的网页），以判断每台设备是什么。这些流量只在你的本地网络内部传输。

通过互联网发送的内容

部分功能需要联系互联网上的服务。这些请求直接从你的设备发出，开发者不会看到。

  • 公网 IP 和国家或地区（Network 标签页）：你的设备向 Cloudflare（www.cloudflare.com）查询你的公网 IP 地址及其所在的国家或地区。如果失败，则向 api64.ipify.org 仅查询 IP 地址。与任何互联网请求一样，这些服务会收到你的公网 IP 地址。不使用账户或令牌。
  • 连接检查（Network 标签页）：App 测量 Cloudflare、Google 和 Quad9 的公共 DNS 服务器响应连接尝试的速度。不会发送任何个人数据。
  • 速度测试（仅在你启动时）：向 Cloudflare 的速度测试服务器（speed.cloudflare.com）下载和上传数据。
  • 你运行的工具：Ping、Traceroute、Port Scanner、DNS Lookup 和 HTTP Inspector 只会联系你输入的主机或 DNS 服务器，不会联系其他任何对象。

这些服务按各自的隐私政策处理请求。

儿童

该 App 不会收集任何人的个人数据，包括儿童。
