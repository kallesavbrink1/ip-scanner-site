English (original)

IP Scanner listar och identifierar enheterna på det lokala nätverk du är ansluten till. Appen har inget konto, ingen analys, ingen reklam och ingen spårning. Utvecklaren får inga data från appen.

Vad som stannar på din enhet

Skanningsresultat, enhetsnamn som du redigerar, anteckningar, favoriter, skanningshistorik och verktygshistorik lagras bara på din enhet. De ingår i enhetens vanliga iCloud- eller datorbackuper, precis som data från vilken annan app som helst. Du kan radera allt i appen under Settings › Forget All Devices, eller genom att ta bort appen.

Appen exporterar eller delar bara data när du väljer det, via systemets delningsark.

Åtkomst till det lokala nätverket

För att hitta enheter ber appen iOS om tillstånd att nå ditt lokala nätverk. Sedan kontaktar den adresser på nätverket (ping, anslutningsförsök på vanliga portar, namnfrågor via Bonjour, UPnP och NetBIOS samt enheternas egna webbsidor) för att ta reda på vad varje enhet är. Den trafiken stannar inom ditt lokala nätverk.

Vad som skickas över internet

Vissa funktioner behöver kontakta tjänster på internet. Anropen kommer direkt från din enhet; utvecklaren ser dem aldrig.

  • Publik IP och land (fliken Network): din enhet frågar Cloudflare (www.cloudflare.com) efter din publika IP-adress och det land den verkar finnas i. Om det misslyckas frågar den api64.ipify.org bara efter IP-adressen. De här tjänsterna får din publika IP-adress som en del av varje internetanrop. Inget konto eller token används.
  • Anslutningskontroll (fliken Network): appen mäter hur snabbt de publika DNS-servrarna hos Cloudflare, Google och Quad9 svarar på ett anslutningsförsök. Inga personuppgifter skickas.
  • Hastighetstest (bara när du startar det): data laddas ned från och upp till Cloudflares hastighetstestservrar (speed.cloudflare.com).
  • Verktyg du kör: Ping, Traceroute, Port Scanner, DNS Lookup och HTTP Inspector kontaktar den värd eller DNS-server du anger, och inget annat.

De här tjänsterna hanterar anropen enligt sina egna integritetspolicyer.

Barn

Appen samlar inte in personuppgifter från någon, inte heller från barn.

Ändringar

Om policyn ändras publiceras den nya versionen på den här sidan med ett nytt datum.
